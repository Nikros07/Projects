# Umfeld: Werkzeuge und fremder Code

Ordner auf dem Rechner, die **nicht** von mir geschrieben sind. Sie gehören hierher,
weil man sonst nicht versteht, was da liegt — und damit niemand sie versehentlich
für eigene Projekte hält.

| Ordner | Was es ist | Quelle |
|---|---|---|
| `flipper-firmware` | Offizielle Flipper-Zero-Firmware | [flipperdevices/flipperzero-firmware](https://github.com/flipperdevices/flipperzero-firmware) |
| `momentum-firmware` | Custom-Firmware Momentum | [Next-Flip/Momentum-Firmware](https://github.com/Next-Flip/Momentum-Firmware) |
| `unleashed-firmware` | Custom-Firmware Unleashed | [DarkFlippers/unleashed-firmware](https://github.com/DarkFlippers/unleashed-firmware) |
| `protopirate`, `Ubers-SD-Files-main` | Flipper-Zubehör und SD-Dateien | Drittanbieter |
| `test 1` | Kopie des *caveman*-Plugins von Julius Brussee | Drittanbieter — sauber klonen statt `git init` |
| `HermesWorkspace`, `NotebookLM`, `Trae` | Dokumente bzw. installierte Software | keine Projekte |

**Regel:** Fremder Code wird geklont, nicht kopiert, und bekommt hier keine
eigene Versionierung. Ob etwas Projekt oder Werkzeug ist, steht in dieser Liste —
der Ordnername verrät es nicht.

> Hinweis zu Sicherheits-Werkzeugen auf dem Desktop (z. B. Crack-/Analyse-Tools):
> Nutze solche Programme nur an eigenen Geräten und Netzen oder mit schriftlicher
> Erlaubnis.
